## Primary test

Wilcoxon signed-rank on paired (M1 − B5) in normalised regret R, two-sided
α = 0.05. Five exact ties dropped (M1 and B5 shipped the same config).

| | |
|---|---|
| N | 50 (45 non-ties) |
| mean V | B5 **0.560** · M1 **0.562** · B0 0.456 |
| mean R | B5 0.130 · M1 0.111 |
| M1 better V | **29 / 50** (16 worse, 5 ties) |
| Wilcoxon median ΔR | **−0.025** (M1 lower regret) |
| p | **0.013** |
| bootstrap 95% CI for median ΔR | **[−0.038, 0.000]** |
| walk-backs | 0/50 both |

`h1_m1_better` is true on the pre-registered rule (median < 0 and p < 0.05).

## How to read it

The pre-reg said the **confidence interval is the headline**, not the p-value.
The interval **touches 0**. The MDE we powered for was **0.10** in R; the
observed median is **0.025**, four times smaller. Mean ΔV is **+0.002**.

So: a statistically detectable, **practically tiny** edge for extrapolating
from the same eleven labels B5 already has. It is not “simulation reduces live
A/B tests.” Both methods still sit ~0.10 above shipping default. That gap
remains the information channel (pay for delayed V), not the surrogate.

Exploratory n=5 had M1 *losing* (−0.011 V). The confirmatory sign flip is real
and small. Seed 11’s exploitation event did not recur as a 50-seed mean.

## What this does not license

- Not H2 / H1-original / H4 (B1 and B3 were not run).
- Not H3 (Q8 remains exploratory).
- Not M2. The amendment deferred RL until H1 vs B5 is positive *in some
  fidelity region*. The p-value is positive; the effect is not large enough to
  spend a sequential-design agent on. Revisit only if a later fidelity region
  shows a gap worth the complexity.
